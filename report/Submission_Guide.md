# Assignment submission guide

## Deliverables included in this project

- EDA notebook and script: `notebooks/01_eda_and_data_cleaning.ipynb`,
  `scripts/inspect_dataset.py`, and `report/results/eda/`.
- Classical feature/SVM approach: `notebooks/02_approach_1_classical_ml.ipynb`
  and `scripts/train_classical.py`.
- MobileNetV2 transfer-learning approach:
  `notebooks/03_approach_2_deep_learning.ipynb` and `scripts/train_deep.py`.
- Metrics, confusion matrices, and single-image demo:
  `notebooks/04_model_evaluation_and_demo.ipynb`, `scripts/evaluate_models.py`,
  and `main_demo.py`.
- Written report: `Assignment2_Avocado_Report.md` and
  `Assignment2_Avocado_Report.docx` (generated by `python -m scripts.build_report`).
- Code setup and commands: `README.md` and `requirements.txt`.

The original brief describes four ripeness stages, but the supplied data labels
are `blackspot`, `canker`, `fresh`, and `grenning`. The current measured results
apply to those four folder labels and must not be submitted as ripeness-stage
classification results.

## Remaining items that need your account or personal input

1. **GitHub:** create/publish a repository from this project, review the
   `.gitignore`, and do not upload private data without permission. The data
   folders and trained model weights are ignored by Git by default. If model
   weights must be shared, consider Git LFS or a permitted external storage
   link. Add the public repository URL to the report.
2. **Google Colab:** upload the notebook files and the required code/data
   through your permitted Drive workflow, open the notebooks in Colab, run all
   cells, then set the notebook's General access to “Anyone with the link” /
   Viewer if allowed by your institution. Add the share URL to the report.
   Do not assume the runtime contains your local data or saved checkpoints.
3. **30-minute recording:** record your own screen and voice; a suggested
   timed outline is below. Add the resulting recording link to the report.
4. **Personal time allocation:** answer the final question using your own
   actual experience. No personal work-time log was collected for this run.
5. **Dataset/assignment alignment:** confirm with the instructor whether the
   supplied condition labels are accepted for the ripeness-stage assignment.
   If the assignment strictly requires underripe/breaking/ripe/overripe classes,
   obtain the corresponding labeled dataset and retrain before claiming that
   objective is met.
